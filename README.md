# 원(교)감 업무 길라잡이 챗봇

유치원 원감·초등 교감이 업무 중 막히는 부분을 **물어보면, 길라잡이의 해당 위치로 바로 찾아가는** 웹 프로그램입니다.
설치·로그인 없이 브라우저에서 바로 사용합니다.

- 바로 열기: https://munjiny70-bot.github.io/AI-JINI/gyowongam-chatbot/
- 파일로 쓰기: `index.html`을 내려받아 크롬·엣지로 열기 (인터넷 없이도 동작)

## 담긴 자료

| 자료 | 내용 | 비고 |
|---|---|---|
| 원감 업무 길라잡이 2026 (세종특별자치시교육청) | 상황별 길잡이 10, 규정·지침 23, 계약제교원 운영 지침 본문·질의응답 | 1순위 근거 |
| 원(교)감 SOS 교직실무 도우미 | 연중·월별·부록 업무 62가지, 서식·기안문, 화면 예시 | 2024 서울특별시교육청 계열 실무자료를 세종 기준으로 재구성 |
| 교감 업무추진 길라잡이(초등 교감편) (경기도교육청) | 본문 92쪽 | 경기·초등 기준 참고 자료 |

## 사용 방법

1. 첫 화면의 **물어보세요** 칸에 궁금한 업무를 적고 **찾기** (예: 질병휴직 기간제 채용, 육아시간, 공가, 계약해지 사유)
2. 가장 알맞은 쪽·항목으로 **바로 이동**하고, 질문 낱말을 노랗게 표시합니다.
3. 오른쪽 아래 챗봇 창에 **원문에서 찾은 부분**이 나오고, 단추를 누르면 그 위치로 이동합니다.
4. 휴대폰은 첫 화면의 **QR코드**로 엽니다.

## 유의사항

- 업무 참고용이며 법적 효력이 없습니다. 실제 처리 전에는 국가법령정보센터와 소속 교육청의 최신 지침 원문을 확인하세요.
- 각 길라잡이의 저작권은 발간 기관에 있습니다. 세종이·자람이 캐릭터와 교육청 로고는 세종특별자치시교육청의 상징물입니다.
